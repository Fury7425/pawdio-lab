How it works

A number becomes a curve.

1
Generate
A sine, impulse, or log chirp with a fade envelope, written by the Rust engine.
2
Record, aligned
Input and output streams run at once with a safety margin; cross-correlation lines the return back up.
3
Compare
Magnitude ratios become the curve, averaged across repeats.

The whole trick

curve(f) = 20 · log₁₀
( rec(f) / ref(f) )

No magic, no model fitting. The curve is the measured ratio between what came back and what went out.
