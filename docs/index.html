Wireless mode

Bluetooth, without the guesswork.

A wireless link adds a delay that moves and a clock that drifts. Wireless mode wraps the excitation in coded timing markers and corrects both before any curve is drawn. Latency ignores it on purpose: link delay is what latency reports.

  • Lock on. Normalised cross-correlation finds the markers in the capture.
  • Measure drift. The spacing of the two end markers gives the clock error.
  • Resample. The captured window goes back to nominal length.
  • Or refuse. A capture that will not lock is rejected, not drawn wrong.
