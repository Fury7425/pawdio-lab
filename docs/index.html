What it measures

Latency Output-to-input delay via FFT cross-correlation with sub-sample interpolation; per-preset calibration removes the system baseline. 5 presets
Frequency response Log chirp sweep, stereo or mono-guided; exports PNG and Squiglink text. 20 Hz to 20 kHz
ANC / transparency Guided four-mode capture turns marketing claims into a per-frequency attenuation curve. 4 modes
Library / compare Runs persist to a local SQLite library; overlay any two stored measurements. Currently in beta. local SQLite
Input monitor Real-time dBFS meter with peak hold and clip detection, plus pink noise for placement checks. live
THD, balance, crosstalk, isolation Running on the experimental page while the numbers are validated. in validation

Method

Play a known signal record what returns compare to the reference

The Rust engine generates a sine, impulse, or log chirp with a fade envelope; input and output streams run simultaneously with a safety margin; FFT cross-correlation aligns the recording and magnitude ratios become the curve, averaged across repeats. 20 · log10(rec / ref)
